# Batch Day Checklist (60–90 min, once a week)

The 90%: drafting is systematized. You: pick, record, export.

## Draft (15 min)

- [ ] Pull 10 scripts (from `scripts/scripts-10.md` or generated fresh)
- [ ] Mark 5 to produce this week (variety: 1 hook-test, 3 topic, 1 CTA)
- [ ] Adjust any bracketed words to your niche

## Record (25 min)

- [ ] Record voice, one take per script, calm pace
- [ ] No more than 2 takes per script (perfection is the enemy of batch)

## Edit (30 min)

- [ ] Add on-screen text: bold lines only, big, one at a time
- [ ] Drop 3–5 b-roll clips (desk, walk, notebook, screen recording)
- [ ] Export 9:16, under 60s, no watermark
- [ ] Name files: `niche-hookstyle-topic` (e.g. `calm-question-weeklyreset`)

## File (5 min)

- [ ] Move exported files to `filmed/`
- [ ] Update `calendar/content-calendar.md` with what's ready

## Rule

If a script feels dead on batch day, don't fix it — mark it and move on.
Fix the template once during review, not five times during batch.
