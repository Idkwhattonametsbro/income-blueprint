# Weekly Review Checklist (15 min)

Keep / kill. One change at a time. The loop stays.

## Look at the data

- [ ] Which hook got the most replay or comments? (keep it)
- [ ] Which topic got the most saves? (do more of it)
- [ ] Did anyone ask "where do I get that?" (that's your product signal)

## Decide one change

- [ ] No change — keep running the same batch (fine, especially weeks 1–3)
- [ ] Change hook style (question → command → curiosity)
- [ ] Change topic (same hook, new pain)
- [ ] Change CTA ("save this" → "want the template?")
- [ ] Change format (faceless → face, or Shorts → screen)

## Log it

- [ ] Update `changelog.md` with the one line you changed and why
- [ ] Update the calendar's experiment grid

## The 15-post rule

If nothing after 15 posts: swap topic or format — not the whole life plan.
$100/month is not the scoreboard for post 7.
