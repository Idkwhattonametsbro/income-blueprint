# Setup Checklist (~2 hours, once)

Goal: one account, one bio, one folder system, one loadout written down.

## Before you start

- [ ] Read `blueprint.md` section 1–2 (10 min)
- [ ] Write your north star line at the top of a notes file
- [ ] Pick: format A_ / platform B_ / product C_ (write them down)

## Create the account

- [ ] One platform only (home) + one mirror (later)
- [ ] Same username everywhere (check it's free)
- [ ] Bio formula: who + result + "new" (e.g. "calm weekly systems · new")
- [ ] Profile photo: simple, readable at small size (Canva free)
- [ ] Turn on notifications off (protect your attention)

## Phone folder system

- [ ] Create three folders: `hooks / filmed / posted`
- [ ] Set a weekly reminder: "batch day" (e.g. Sunday 19:00)
- [ ] Download a free editor (CapCut) and open it once

## Product seed (30 min)

- [ ] Make the one-page weekly reset (`pack/weekly-reset.md`) in Google Docs
- [ ] Export to PDF, upload to Drive, copy the view link
- [ ] Put the link in your bio placeholder

## First batch

- [ ] Pick 5 scripts from `scripts/scripts-10.md`
- [ ] Record voice for 1 (test, not perfect)
- [ ] Export it, watch it once, note one thing to fix

Done. You now have a system, not just an idea.
