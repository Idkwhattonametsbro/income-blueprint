# Posting Checklist (10–15 min per post)

## Before upload

- [ ] Video: 9:16, under 60s, no watermark
- [ ] Hook is the first thing heard
- [ ] One freebie reference max

## On upload

- [ ] Title/caption: use the title formula (3–5 keywords, same as spoken line)
- [ ] Hashtags: 3 max or none
- [ ] Pin comment: "free [thing] → link in bio" (after 5–10 posts exist)
- [ ] Schedule or post at evening local time

## After upload

- [ ] Reply to every comment with a question back
- [ ] Log it in `calendar/content-calendar.md` (views/saves/comments)
- [ ] Move the file from `filmed/` to `posted/`

## 10% rule

Uploading and answering humans is the part only you can do.
No bots, no engagement pods, no fake views — ever.
