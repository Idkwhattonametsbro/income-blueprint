# Marketing Calendar — Weaving Promos into Organic Content

Goal: ~5 posts/week. 3 organic (from your blueprint scripts) + 2 promos (from
`shorts-10-pack-promo.md`). This keeps the channel useful AND building the funnel.

## Weekly template

| Day | Post type | Source |
|-----|-----------|--------|
| Mon | Organic | blueprint scripts (e.g. "The 2-2-2 rule") |
| Tue | Promo | promo scripts 1–5 (rotate) |
| Wed | Organic | blueprint scripts |
| Thu | Organic | blueprint scripts |
| Fri | Promo | promo scripts 6–10 (rotate) |
| Sat | Rest / batch | batch next week's scripts |
| Sun | Rest / reset | post your own weekly reset live |

## Milestones

- **Before pack is ready:** only organic + "free template in bio" (the weekly reset). Collect the asks — that's your signal.
- **Pack ready (week 3–4):** flip on the promos. Announce once: "the full kit is live."
- **First sales:** make promo 4/5 stars — the ones that show the product.
- **Every 15 posts:** keep/kill review (same as blueprint). If promos get no clicks, change the CTA, not the product.

## CTA setup (one-time, 20 min)

1. **Link in bio** → Gumroad product page (fastest) or a Linktree with both links
   (free template + full pack).
2. **Pinned comment on every post:** "Free weekly reset → link in bio. Full pack when it's ready."
3. **Bio line:** "calm weekly systems · free template ↓ · 8-page kit $7"

## Honest note

The channel is the marketing engine, not the product. It can take 1–3 months
to build a small audience. The product (Etsy/Gumroad) is what sells while you
sleep — the channel feeds it. Both together = the machine. Neither alone is fast.
