## How to make the sellable PDFs (one-time, ~30 min)

1. Open each file in Chrome/Safari (phone or computer).
2. Print → "Save as PDF" → scale 100%, background graphics ON.
3. Name them: `calm-week-system_01_weekly-reset.pdf` ... etc.
4. Bundle the 8 pages + cover into one ZIP (or one combined PDF).
