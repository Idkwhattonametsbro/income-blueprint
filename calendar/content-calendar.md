## Cadence

- Batch day: 10 scripts in one sitting (60–90 min)
- Post 4–5×/week, evenings local time
- Mirror each post to the second platform, no extra edit

## Decision at post 15

- **Continue** — if any post got unusual saves/comments, double down on that hook + topic + CTA
- **Pivot topic** — if watch time is flat, same format, new pain
- **Pivot format** — if you hate the process, face or screen format
- **Stop + rethink** — if the loop itself feels wrong, change one line in changelog.md and re-run 15
