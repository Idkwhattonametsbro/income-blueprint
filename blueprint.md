# Flexible $0 starter blueprint

**Goal:** something that can grow toward ~$100/month first, without pretending a GitHub repo prints cash.
**Constraints:** $0 budget · ~90% of *repeatable* work systematized · stay away from haram (interest, gambling, adult, scams) · not a religious channel.
**Rule:** this is a kit of modules. Swap any module. Don't run four businesses until one has a pulse.

---

## What you actually get from this file

Not a locked 90-day prison. Four layers you can remix:

1. **North star** — one sentence you can change
2. **Modules** — pick 1 format + 1 product type + 1 distribution
3. **Weekly loop** — the 90% system vs the 10% only you can do
4. **Upgrade ladder** — when (not if) to add a second idea

Change anything in `[brackets]`.

## 2. Modules (mix, don't stack on day 1)

### A. Format (pick one to start)
- **A1 Faceless Shorts** — voice + on-screen text + simple b-roll or screenshots. Fastest.
- **A2 Talking head on phone** — higher trust, more energy, less "AI slop" feel.
- **A3 Screen tutorial** — best if the product is a template/sheet.
- **A4 Carousel / static** — TikTok photos, later YouTube is optional.

Default if tired and broke: **A1 + a few A3**.

### B. Platform (pick one "home", one "mirror")
- Home: **YouTube Shorts** (search lasts) *or* **TikTok** (faster test)
- Mirror: post the same file to the other, no extra edit

Don't open Instagram + a newsletter + a podcast in week 1.

### C. Offer (pick one product type)
All $0 to *make*. Selling can wait until you have even a tiny signal.

- **C1 Template pack** — weekly planner, job-hunt tracker, budget-without-interest sheet (no riba products), content calendar
- **C2 Prompt / script / swipe pack** — captions, outreach messages, video hooks
- **C3 Mini guide PDF** — 8–15 pages, one problem
- **C4 Asset pack** — thumbnails layouts, phone wallpaper set, Canva-free layouts you designed

Price later: **$5–12** or "pay what you want" on a free host (Payhip / Gumroad when you have an email). Until then the "product" is a **free Google Drive / PDF** that collects nothing illegal and trains you to finish things.

### D. Traffic (only after 5–10 posts exist)
- Hooks in the first second
- Same 3–5 keywords in title + spoken line + on-screen text
- Pin a comment: "free [thing] / full pack when it's ready"
- Reply to every comment for the first month (this is part of the 10%)

No bots. No fake views. No stolen clips.

## 3. The 90 / 10 split (this is the "automation")

**90% = batch + templates** (generate anytime from this repo):

- 20 hooks (`scripts/hooks-20.md`)
- 10 short scripts (`scripts/scripts-10.md`)
- on-screen text blocks
- thumbnail/title formulas (`scripts/title-formulas.md`)
- product outline + page list (`pack/pack-outline.md`)
- posting checklist (`checklists/posting.md`)
- a simple content calendar (`calendar/content-calendar.md`)

**10% = only you (non-negotiable):**

- record or approve voice / film a walk
- export from CapCut (free) or similar
- create the free YouTube/TikTok account
- tap upload
- answer humans
- **never paste tokens or passwords here**

There is no honest 24/7 bot that uploads, grows, and cashes out on $0. The system makes the *thinking and drafting* almost free so your hour is only record + post.

## 4. Weekly loop (loose, not a prison)

Do this when you have energy. Skip a day; don't skip the *loop* for two weeks.

**Once (setup, ~2 hours)** — `checklists/setup.md`
1. Choose A + B + C from section 2. Write them at the top of a notes file.
2. Create one account. Same username if possible.
3. One-line bio: who + result + "new".
4. Folder on your phone: `hooks / filmed / posted`.

**Batch day (60–90 min, once a week)** — `checklists/batch-day.md`
Ask your agent: "batch 10 scripts for [niche], Shorts, faceless."
You pick 5, record voice or screen, export 5 files.

**Post days (10–15 min × 4–5)** — `checklists/posting.md`
Upload → 3 hashtags max or none → pin comment → done.
Best guess times: evenings local. Change if data says otherwise.

**Light review (15 min, once a week)** — `checklists/review.md`
Keep / kill:
- which hook got replay or comments?
- did anyone ask "where do I get that?"
If nothing after **15 posts**, swap **topic or format**, not the whole life plan.

## 5. 15-post experiment (the only "strict" bit)

You're not married to a niche. You *are* married to finishing a small test.

- Posts 1–5: test **hooks** (same topic, different first lines)
- Posts 6–10: test **topics** (same hook style)
- Posts 11–15: test **CTA** ("save this" vs "want the template?")

Then choose:
- **Continue** if any post got unusual saves/comments
- **Pivot topic** if watch time is dead
- **Pivot format** (faceless → face, or Shorts → screen) if you hate the process

$100/month is not the scoreboard for post 7.

## 6. When money can appear (still $0 to start)

Rough, honest sequence:

| Stage | What "winning" looks like | Money? |
|-------|---------------------------|--------|
| 0–15 posts | you finished a loop | no |
| small audience or 1 video that saves | people ask for the file | free download |
| repeat asks | pack v1, $7–9 | first $ |
| a few sales or affiliates | nicer pack + 1 longer video | toward $100/mo |
| real channel | more products or freelance from DMs | growth |

**Halal-enough money ideas that fit this machine**
- sell the pack
- freelance the skill the videos teach (one-off, not a second company yet)
- YouTube ads *later* if the content stays clean (not a plan for month 1)
- not: interest, betting, fake guru, stolen movies, engagement pods
